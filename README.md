# ftupb-feedback

Melaporkan **bug** dan memberi **masukan** untuk sistem Fakultas Teknik UPB.

## Cara melapor

1. Buka tab **Issues → New issue**
2. Pilih **Laporan Bug** atau **Masukan**
3. Isi form selengkap mungkin, sertakan screenshot jika ada

⚠️ Laporan ini bisa dilihat publik. Jangan menulis password, NIM/NIK, nomor HP, atau data pribadi lain.
